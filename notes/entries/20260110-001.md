## 知识点

- RSC 在服务端渲染，零 JS bundle 发给客户端，天然减少 TTI
- 可以直接 await 数据库 / 文件系统，不需要 useEffect
- 与 Client Component 通过 `use client` 边界分离
- Server Component 不能有 state / 事件处理器，这些必须下沉到 Client Component

## 我的感悟

架构上尽量把数据获取留在 Server Component，把交互 UI 拆成小粒度 Client Component。这个思路和 MVC 的关注点分离类似，但 RSC 把边界推到了网络层。
